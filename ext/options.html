MezTal Feedback — Setup

Connect the private backup repo so notes are saved to the cloud (not just this browser).

How to make the token (2 min, one-time):
  1. Open github.com/settings/personal-access-tokens/new (fine-grained token)
  2. Resource owner: gigorbust  ·  Repository access: Only select repositories → meztal-feedback-data
  3. Permissions: Repository permissions → Contents = Read and write
  4. Generate, copy the github_pat_… value, paste it above, click Save.

The token is stored only in this browser (chrome.storage) and used only to write to that one private repo.
